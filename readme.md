# 线粒体++

本模组添加了一些好玩的能量器官。

## 1.脉冲线粒体【线粒体】

每5秒触发1x过载1秒(每稀有1级，倍率+1x、时长+0.8秒)，战斗外不生效。

## 2.叶绿体【辅助】

连接到的线粒体的过载强度+25%(每稀有1级，+10%)，
自身过载时过载强度额外+25%，
闪避穿过任意敌方子弹时过载强度+75%(每稀有1级，+30%)，
自身过载时过载强度额外+50%，
持续5秒(每稀有1级，+3秒)。

## 3.五碳溶糖体【主动技能】

触发主动技能时水解1个DNA，获得2x过载5秒(每稀有1级，倍率+1x、时长+1秒)。

## 4.格挡聚能环【线粒体】

通过副攻击键触发，无敌1秒(每稀有1级，+0.25秒)，冷却1秒(每稀有1级，-0.15秒)，
在0~0.5秒内格挡伤害获得3x过载3秒(每稀有1级，时长+1秒)，完美窗口随格挡时长等比延长(每稀有1级，+0.125秒)，
在完美窗口外格挡有50%概率失败(每稀有1级，-4%)。

## 5.ATP水解酶【攻击修改器】

每50%强度的过载，伤害+20%(每稀有1级，+10%)，可被修改：当过载时，连接的攻击获得已连接的修改器加成。

## 6.ATP转移酶【线粒体】

用于传递过载效果，自身过载时，连接到的细胞器也过载。
