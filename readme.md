# 线粒体++

本模组添加了一些好玩的能量器官。

## 1.脉冲线粒体【线粒体】

每5秒触发过载1秒，战斗外不生效。

## 2.叶绿体【辅助】

连接到的线粒体的过载强度+10%（过载时额外+10%），
受到激光或射线类伤害时+60%（过载时额外+40%），
擦过激光或射线类伤害时+30%（过载时额外+30%）。

## 3.五碳溶糖体【主动技能】

触发主动技能时水解1个DNA，获得2x过载8秒

## 4.格挡聚能环【线粒体】

通过副攻击键触发，无敌1秒，冷却10秒，
在0\~0.5秒内格挡伤害获得3x过载4秒，
在0.5\~1秒内格挡有50%概率失败。

## 5.ATP水解酶【攻击修改器】

每过载1秒，伤害+5%，可被修改：当过载时 获得已连接的修改器加成

## 6.ATP转移酶【线粒体】

用于传递过载效果，自身过载时，连接到的细胞器也过载
